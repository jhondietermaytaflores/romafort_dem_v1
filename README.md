# RomaFort_web

Prototipo de demostración para Importadora Romaforte. Está construido con React y Vite, utiliza datos ficticios y conserva los cambios en el almacenamiento local del navegador.

Acceso demo: admin@romaforte.bo / romaforte123

Ejecuta npm install y después npm run dev. Incluye resumen, ventas, inventario, compras, clientes, reportes y configuración. Se pueden registrar ventas de muestra, movimientos de stock, órdenes pendientes y clientes, filtrar listas y descargar CSV.

No hay conexión con la base real. Este prototipo no sustituye las reglas, permisos ni autenticación del backend de RomaForte.
